# Character Counter Challenge
A simple **Character Counter Web App** built with HTML, CSS, and JavaScript.  
This project was created as a coding challenge to practice real-time input handling and DOM manipulation.

## 🚀 Features
- Live character counting
- Real-time UI updates
- Input restriction at max limit (150 characters)
- Visual warnings (orange/red states)
- Simple and responsive design

## 🛠️ Built With
- HTML5
- CSS3
- Vanilla JavaScript
